معرفی الگوریتم‌ها
Caesar
در رمز سزار هر حرف با یک انتقال ثابت روی الفبای ۲۶ حرفی جابه‌جا می‌شود:

Encryption: E_k(x) = (x + k) mod 26
Decryption: D_k(y) = (y - k) mod 26

فضای کلید فقط ۲۶ حالت دارد؛ بنابراین همهٔ کلیدها را می‌توان بررسی کرد. روش کای‌دو نیز محتمل‌ترین متن انگلیسی را از میان خروجی‌ها انتخاب می‌کند.

نحوهٔ کار

کلید یک عدد صحیح است که با پیمانهٔ ۲۶ نرمال می‌شود.
فقط حروف انگلیسی جابه‌جا می‌شوند و بزرگی یا کوچکی آن‌ها حفظ می‌شود.
فاصله‌ها، اعداد، نشانه‌های نگارشی و حروف غیرانگلیسی بدون تغییر باقی می‌مانند.
رمزگشایی با اعمال انتقال معکوس روی همان کلید انجام می‌شود.
رمزشکنی و تحلیل

نمایش هر ۲۶ خروجی ممکن با Brute Force
تشخیص خودکار کلید با مقایسهٔ کای‌دو و فراوانی استاندارد حروف انگلیسی
روش مقایسه‌ای n-gram بر پایهٔ دوگرام‌ها و سه‌گرام‌های رایج
محاسبهٔ فراوانی حروف، شاخص تطابق و آنتروپی شانون
مقایسهٔ روش‌های مختلف رمزشکنی روی متن‌هایی با طول متفاوت
اندازه‌گیری نرخ موفقیت و زمان اجرای رمزگذاری، رمزگشایی و حمله
تولید گزارش‌های CSV و نمودارهای فراوانی، موفقیت و زمان اجرا
از آنجا که انتقال سزار فقط برچسب حروف را جابه‌جا می‌کند، توزیع فراوانی، شاخص تطابق و آنتروپی تک‌حرفی متن حفظ می‌شوند. همین ویژگی و فضای کلید کوچک، شکستن این رمز را بسیار ساده می‌کند.

Substitution
در رمز جانشینی، کلید یک جایگشت کامل از حروف الفباست و هر حرف همیشه به یک حرف ثابت دیگر تبدیل می‌شود:

Encryption: C_i = π(P_i)
Decryption: P_i = π⁻¹(C_i)

این تبدیل فراوانی حروف را حفظ می‌کند؛ در نتیجه تحلیل فراوانی و مدل‌های n-gram اطلاعات ارزشمندی برای بازیابی متن فراهم می‌کنند. این بخش از متن‌های انگلیسی و فارسی پشتیبانی می‌کند.

نحوهٔ کار

کلید یک نگاشت دوسویی و کامل از حروف متن اصلی به حروف متن رمز است.
امکان تولید کلید تصادفی یا دریافت یک جایگشت معتبر از کاربر وجود دارد.
رمزگشایی با معکوس‌کردن نگاشت کلید انجام می‌شود.
قالب متن، فاصله‌ها، اعداد، نشانه‌ها و بزرگی حروف انگلیسی حفظ می‌شوند.
در پردازش فارسی، شکل‌های عربی حروف به نویسه‌های استاندارد فارسی تبدیل می‌شوند.
رمزشکنی و تحلیل

حملهٔ پایه با مرتب‌سازی حروف متن رمز برحسب فراوانی
استفاده از جدول‌های مرجع مستقل برای زبان‌های انگلیسی و فارسی
اصلاح کلید اولیه با Hill Climbing و جابه‌جایی مقادیر نگاشت
استفاده از Simulated Annealing برای پذیرش کنترل‌شدهٔ بعضی حرکت‌های ضعیف‌تر و فرار از جواب محلی
امتیازدهی متن‌های کاندید با مدل‌های bigram و trigram

Vigenere
ویژنر از یک کلید متنی دوره‌ای استفاده می‌کند؛ بنابراین مقدار انتقال در جایگاه‌های مختلف یکسان نیست:

Encryption: C_i = (P_i + K_(i mod m)) mod 26
Decryption: P_i = (C_i - K_(i mod m)) mod 26

در رمزشکنی، ابتدا طول کلید با ترکیب شاخص تطابق و آزمون کاسیسکی تخمین زده می‌شود؛ سپس هر ستون مانند یک رمز سزار با آزمون کای‌دو شکسته می‌شود.

نحوهٔ کار

کلید یک رشتهٔ متنی است که به‌صورت دوره‌ای روی حروف متن تکرار می‌شود.
هر حرف کلید مقدار انتقال متفاوتی برای حرف متناظر در متن اصلی ایجاد می‌کند.
فقط حروف انگلیسی وارد محاسبات پیمانه‌ای می‌شوند.
فاصله‌ها، اعداد، نشانه‌ها و حروف فارسی تغییر نمی‌کنند و باعث جلو رفتن کلید نمی‌شوند.
اعتبار کلید پیش از رمزگذاری یا رمزگشایی بررسی می‌شود.
رمزشکنی و تحلیل

پاک‌سازی متن و جداسازی حروف A-Z برای محاسبات آماری
محاسبهٔ میانگین شاخص تطابق ستون‌ها برای طول‌های مختلف کلید
بررسی فاصلهٔ سه‌گرام‌ها، چهارگرام‌ها و پنج‌گرام‌های تکراری با آزمون کاسیسکی
ترکیب شواهد IC، کاسیسکی و جریمهٔ پیچیدگی برای رتبه‌بندی طول‌های محتمل
تقسیم متن به ستون‌های مستقل پس از تخمین طول کلید
شکستن هر ستون مانند یک رمز سزار با آزمون کای‌دو روی ۲۶ انتقال
رتبه‌بندی متن‌های کاندید با فراوانی حروف، n-gramها و کلمات رایج انگلیسی
نمایش چند پاسخ احتمالی و بازیابی کلید و متن
تحلیل فراوانی حرف، دوگرام، سه‌گرام و مقایسهٔ آنتروپی
آزمایش دقت حرفی، بازیابی کامل متن و بازیابی کامل کلید نسبت به طول متن
اگر طول کلید m باشد، فضای کلید 26^m حالت دارد و Brute Force با افزایش طول کلید به‌سرعت غیرعملی می‌شود. روش آماری پروژه به‌جای بررسی تمام کلیدهای کامل، طول کلید را تخمین می‌زند و هر حرف آن را جداگانه بازیابی می‌کند.

Hill
رمز هیل حروف را به بردارهای عددی تبدیل می‌کند و هر بلوک را با ماتریس کلید ضرب می‌کند:

Encryption: C = K × P mod 26
Decryption: P = K⁻¹ × C mod 26

ماتریس کلید باید در پیمانهٔ ۲۶ وارون‌پذیر باشد. این بخش امکان بررسی اعتبار ماتریس، کار با اندازه‌های مختلف بلوک و بازیابی کلید از نمونه‌های متن اصلی و متن رمز را دارد.

نحوهٔ کار

حروف متن به اعداد صفر تا ۲۵ تبدیل و در بردارهای هم‌اندازه با ماتریس کلید گروه‌بندی می‌شوند.
هر بلوک در ماتریس کلید ضرب و نتیجه در پیمانهٔ ۲۶ محاسبه می‌شود.
رمزگشایی با ماتریس معکوس پیمانه‌ای کلید انجام می‌شود.
اعتبار کلید با بررسی دترمینان و وجود معکوس آن در پیمانهٔ ۲۶ کنترل می‌شود.
اندازه‌های مختلف ماتریس کلید پشتیبانی می‌شوند.
برای بلوک پایانی ناقص، شیوهٔ padding قابل انتخاب است.

چند نمونهٔ سریع
Caesar
python main.py encrypt --text "Hello, World!" --key 3
python main.py decrypt --text "Khoor, Zruog!" --key 3
python main.py brute-force --text "Khoor, Zruog!"
python main.py crack --text "Khoor, Zruog!"

Substitution
python main.py generate-key --language en --seed 1405
python main.py encrypt --text "Hello world!" --key zyxwvutsrqponmlkjihgfedcba
python main.py break --language en --algorithm frequency --input output/ciphertext.txt

Vigenere
python main.py encrypt --text "Attack at dawn!" --key LEMON
python main.py decrypt --text "Lxfopv ef rnhr!" --key LEMON
python main.py break --input output/ciphertext.txt --max-key-length 15

Hill
python main.py hill-encrypt --text "HELP" --key-matrix "3,3;2,5" --padding none
python main.py hill-decrypt --text "HIAT" --key-matrix "3,3;2,5" --padding none
python main.py hill-attack --plaintext "HELP" --ciphertext "HIAT" --block-size 2
