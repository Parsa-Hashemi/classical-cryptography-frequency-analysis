# رمز هیل (Hill Cipher)

در این پروژه رمز هیل را پیاده‌سازی کرده‌ایم. برنامه سه کار اصلی انجام می‌دهد: رمزگذاری با ماتریس کلید، رمزگشایی و پیدا کردن کلید از روی متن اصلی و متن رمز متناظر.

## ساختار پروژه

```text
hill_project/
├── src/
│   ├── hill_cipher.py
│   ├── utils.py
│   └── __init__.py
├── tests/
│   └── test_hill_project.py
├── data/
│   └── sample_plaintext.txt
├── docs/
│   └── README.md
├── benchmarks/
│   ├── hill_standard_examples.csv
│   ├── hill_performance_by_text_length.csv
│   └── hill_performance_by_text_length.png
├── output/
├── main.py
├── README.md
└── requirements.txt
```

- `src/hill_cipher.py`: محاسبات ماتریسی، رمزگذاری، رمزگشایی و بازیابی کلید
- `src/utils.py`: توابع سادهٔ مربوط به حروف انگلیسی
- `tests/test_hill_project.py`: تست مثال‌های استاندارد، padding و حملهٔ متن معلوم
- `data/sample_plaintext.txt`: متن نمونه برای ورودی فایل
- `benchmarks/hill_standard_examples.csv`: نتیجهٔ مثال‌های استاندارد ۲×۲ و ۳×۳
- `benchmarks/hill_performance_by_text_length.csv`: زمان اجرا و نرخ موفقیت برای طول‌های مختلف متن
- `benchmarks/hill_performance_by_text_length.png`: نمودار زمان و موفقیت benchmark
- `output/`: محل ذخیرهٔ خروجی‌های اجرای برنامه

## نصب و اجرا

داخل پوشهٔ `hill_project` این دستورها را اجرا کنید:

```powershell
python -m pip install -r requirements.txt
python main.py
```

اگر `main.py` را بدون آرگومان اجرا کنید، همین سه عملیات از طریق منو در دسترس هستند.

### رمزگذاری

```powershell
python main.py hill-encrypt --text "HELP" --key-matrix "3,3;2,5" --padding none
```

نتیجه:

```text
HIAT
```

برای خواندن متن از فایل می‌توان به‌جای `--text` از `--input` استفاده کرد:

```powershell
python main.py hill-encrypt --input data/sample_plaintext.txt --key-matrix "3,3;2,5" --output output/ciphertext.txt
```

### رمزگشایی

```powershell
python main.py hill-decrypt --text "HIAT" --key-matrix "3,3;2,5" --padding none
```

خروجی:

```text
HELP
```

### پیدا کردن کلید از متن معلوم

```powershell
python main.py hill-attack --plaintext "HELP" --ciphertext "HIAT" --block-size 2
```

خروجی:

```text
Recovered key matrix: 3,3;2,5
```

## فرمول رمز هیل

حروف انگلیسی به اعداد پیمانهٔ ۲۶ تبدیل می‌شوند:

```text
A = 0, B = 1, ..., Z = 25
```

اگر اندازهٔ بلوک `n` باشد، هر `n` حرف یک بردار ستونی `P` می‌سازد. کلید هم یک ماتریس مربعی `K` با اندازهٔ `n × n` است. هر بلوک با فرمول زیر رمز می‌شود:

```text
C = K × P  (mod 26)
```

برای نمونه، با کلید زیر:

```text
K = |3 3|
    |2 5|
```

بردار حرف‌های `HE` برابر `(7, 4)` است. بنابراین:

```text
|3 3| × |7| = |33| = |7|  (mod 26)
|2 5|   |4|   |34|   |8|
```

اعداد ۷ و ۸ به حروف `H` و `I` تبدیل می‌شوند.

## شرط معتبر بودن کلید

ماتریس کلید باید در پیمانهٔ ۲۶ وارون‌پذیر باشد. این شرط زمانی برقرار است که دترمینان ماتریس با ۲۶ نسبت به هم اول باشد:

```text
gcd(det(K), 26) = 1
```

در ماتریس نمونه داریم:

```text
det(K) = 3×5 - 3×2 = 9
gcd(9, 26) = 1
```

پس معکوس پیمانه‌ای دترمینان وجود دارد و ماتریس برای رمز هیل قابل استفاده است. اگر این ب.م.م برابر ۱ نباشد، چند بردار مختلف ممکن است به یک بردار رمز یکسان برسند و رمزگشایی یکتا نخواهد بود.

## رمزگشایی و اثبات درستی آن

رمزگشایی با ماتریس معکوس انجام می‌شود:

```text
P = K^(-1) × C  (mod 26)
```

چون `K^(-1) × K = I` است، اگر مقدار `C` را از فرمول رمزگذاری جای‌گذاری کنیم، داریم:

```text
K^(-1) × C
= K^(-1) × (K × P)
= (K^(-1) × K) × P
= I × P
= P  (mod 26)
```

بنابراین هر بلوکی که با یک کلید معتبر رمز شده باشد، با معکوس همان کلید دقیقاً بازیابی می‌شود.

## کامل کردن بلوک‌ها (padding)

طول متن باید مضرب اندازهٔ بلوک باشد. در حالت پیش‌فرض `length` برنامه اطلاعات padding را در انتهای متن آماده‌شده نگه می‌دارد تا هنگام رمزگشایی تعداد حروف اضافه مشخص باشد. گزینهٔ `--padding none` هیچ حرفی اضافه نمی‌کند و فقط زمانی قابل استفاده است که طول متن از ابتدا مضرب اندازهٔ بلوک باشد.

## پیدا کردن کلید با متن معلوم

اگر چند بلوک متن اصلی را به‌صورت ستون‌های ماتریس `P` و بلوک‌های متن رمز متناظر را به‌صورت ستون‌های ماتریس `C` قرار دهیم، رابطهٔ رمزگذاری چنین است:

```text
C = K × P  (mod 26)
```

اگر `P` در پیمانهٔ ۲۶ وارون‌پذیر باشد، دو طرف را از راست در `P^(-1)` ضرب می‌کنیم:

```text
C × P^(-1) = K × P × P^(-1)
C × P^(-1) = K × I
K = C × P^(-1)  (mod 26)
```

برنامه چند بلوک مناسب را انتخاب می‌کند، ماتریس کلید را می‌سازد و نتیجه را روی همهٔ بلوک‌های داده‌شده بررسی می‌کند. اگر نتوان از بلوک‌های متن اصلی یک ماتریس وارون‌پذیر ساخت، کلید با این ورودی‌ها پیدا نمی‌شود.

## پیچیدگی زمانی

برای ماتریس `n × n` و متن دارای `L` حرف:

- ضرب ماتریس در هر بلوک: `O(n²)`
- تعداد بلوک‌ها: `L / n`
- رمزگذاری یا رمزگشایی کل متن: `O(Ln)`
- محاسبهٔ معکوس ماتریس به اندازهٔ ماتریس وابسته است و برای کلیدهای کوچک آموزشی سریع انجام می‌شود.

## نتیجهٔ benchmark

benchmark برای طول‌های ۱۰۰، ۵۰۰، ۱۰۰۰، ۳۰۰۰، ۵۰۰۰ و ۸۰۰۰ حرف اجرا شده است. هر طول برای کلیدهای ۲×۲ و ۳×۳ سی بار آزمایش شده و میانگین زمان رمزگذاری، میانگین زمان رمزگشایی و درصد بازیابی کامل متن در CSV و نمودار ثبت شده‌اند. این فایل‌ها نتیجهٔ ثابت همین اجرا هستند و با اجرای معمولی برنامه تغییر نمی‌کنند.
