THE HILL CIPHER ENCRYPTS LETTERS IN FIXED SIZE BLOCKS. EACH BLOCK IS WRITTEN AS A VECTOR AND MULTIPLIED BY A KEY MATRIX IN MODULO TWENTY SIX. A VALID KEY MATRIX MUST HAVE AN INVERSE, OTHERWISE THE ORIGINAL MESSAGE CANNOT BE RECOVERED UNIQUELY. THIS SAMPLE TEXT CAN BE USED TO TEST FILE INPUT, ENCRYPTION, DECRYPTION, PADDING, AND KEY RECOVERY.
